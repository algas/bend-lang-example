# Bend 2 による精度保証付き区間演算（二進有理数・外向き丸め）

二進有理数 (p − n) / 2^k を端点とする区間演算と、その**包含性**の機械検査済み証明です。
浮動小数点は使いません（Bend 2 の F32 は公理的で、性質を証明できないため）。

## 実行と検査

```bash
bend main.bend              # 実行例
bend PROOF.bend             # すべての law を検査 → ALL PROOFS CHECK
bend PROOF.bend --verdict   # Lean で健全性が証明されたカーネルで再検査（Lean v4.34.0 が必要）
```

チェックアウトから使う場合は `bun <bend>/bend2/main.ts PROOF.bend` でも同じです。

## 証明されている性質（LAWS.bend）

`In(x, a)` は「二進有理数 x が区間 a = [lo, hi] に入る」こと。精度 t（分母 2^t）は任意です。

| law | 内容 |
|---|---|
| `round_down` / `round_up` | 下向き丸めは値を超えず、上向き丸めは値を下回らない |
| `add_incl` | x ∈ a, y ∈ b ⇒ x + y ∈ a ⊕ b |
| `neg_incl` | x ∈ a ⇒ −x ∈ ⊖a |
| `sub_incl` | x ∈ a, y ∈ b ⇒ x − y ∈ a ⊖ b |
| `mul_incl` | x ∈ a, y ∈ b ⇒ x · y ∈ a ⊗ b（端点の符号は任意） |

右辺の x + y、x · y は丸めなしの正確な値、左辺の区間演算は端点を外向きに丸めた結果です。

## 設計のポイント

- **符号付き整数は Nat の対** (p, n) で p − n を表す。順序は a ≤ b ⇔ ap + bn ≤ bp + an となり、符号の場合分けが要らない。
- **二進有理数の順序は交差乗算**：x ≤ y ⇔ 2^ky·zx ≤ 2^kx·zy。加算は分母 2^(kx+ky) にそろえる。
- **丸めは「高速に計算して、検証済みの比較で確かめる」方式**。商は機械語の `Nat.div` で求め、`d·q ≤ a` などを実行時に比較してから採用する（失敗時は安全側の値に倒す。実際には起きない）。健全性の証明は割り算の正しさに依存しない。
- **乗算の包含性**は「y ≥ 0 なら a ≤ x ⇒ a·y ≤ x·y、y ≤ 0 なら逆向き」を基本補題にし、x·y を a·y と b·y で、a·y を a·c と a·d で挟むという標準的な議論をそのまま形式化した。

## 制限

- 「包含性」は二進有理数の点 x について示したもの。実数（完備性）は形式化していない。二進有理数は実数の中で稠密なので、区間演算の基本定理としては標準的な定式化。
- 証明したのは健全性（包含性）のみ。丸めが最良（1 ulp 以内）であることは証明していない。
- 実行時の Nat は u64 で、2^48 を超えるとエラーで停止する（誤った値は返さない）。丸めは 2^t·p / 2^k の形で計算するため、精度 t と分母の指数の合計が大きいとあふれる。実行例の精度は t = 10。
- Bend 2 は 2026年9月公開の若い言語。`--verdict` はパーサとカーネルへの翻訳を証明の対象外としている（README の Limitations 参照）。
