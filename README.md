# 8パズル 可解性プルーバー (Bend 2)

8パズルの盤面ごとに「解ける／解けない」を、**コンパイラが検査する数学的証明**で示すサンプルです。
Bend 2.0.36 で動作確認しています（Bend 1 / HVM 版とは文法も仕組みも別物です）。

| ファイル | 中身 |
|---|---|
| `main.bend` | 盤面・手・ソルバー（反復深化 DFS、4 方向を並列呼び出し）・表示 |
| `LAWS.bend` | 主張（law）。人間が読んで確かめる部分 |
| `PROOF.bend` | 証明。`bend PROOF.bend` が ALL PROOFS CHECK を出せば主張はすべて正しい |

## 実行

```sh
curl -fsSL https://bend-lang.com/install.sh | sh

bend main.bend              # ソルバーを実行
bend PROOF.bend             # 証明をチェック → ALL PROOFS CHECK
bend PROOF.bend --verdict   # Lean で正しさが証明された小さなカーネルで再チェック（Lean 4.34.0 が必要）
bend main.bend -o puzzle8   # ネイティブバイナリにビルド
```

## 証明されていること（LAWS.bend）

- `parity_invariant`：どんな盤面からどんな手順を指しても、「タイルが全部異なり、転倒数が奇数」かどうかは変わらない
- `odd_never_solved`：それが成り立つ盤面からは、**どんな手順でも**ゴールに着かない
- `swap78_unsolvable` / `odd_case_unsolvable`：例題の 2 盤面は解けない
- `hard_solvable` / `reversed_solvable`：例題の 2 盤面は解ける（手順そのものが証拠で、コンパイラが再生して確かめる）

## 証明の考え方

盤面は「空きマスの位置」と「空きマスを除いたタイルを左上から読んだ列」で表しています。この表現では次のようになります。

- 左右の手はタイルの列を変えません。
- 上下の手は、1 枚のタイルが隣の 2 枚を飛び越す（列の 3 要素の回転）だけです。

飛び越されたときに大小関係が反転するのは 2 組だけなので、転倒数の偶奇は変わりません。ゴールの転倒数は 0（偶数）なので、奇数の盤面からは絶対にたどり着けません。

`PROOF.bend` の `par_core` などの総当たり補題（ブール式の恒等式を全 128 通り計算して示すもの）は、スクリプトで生成しています。

## Bend 2 で書くときの注意（ハマった点）

- `if` がなく、`pick(c, a, b)` は**両方の枝を計算**します。重い処理（ソルバーなど）の分岐は `match` で書いてください。
- `Nat` は Zero/Succ の単項表現です。証明には便利ですが、大きな数の計算には `U32` を使います。
- 変数は基本的に 1 回しか使えません。何度も使う値には `+` を付けます。
- 再帰は必ず停止しなければならず、相互再帰は書けません。
